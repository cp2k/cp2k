# Curated Collection of Parameter Data Files

Note that some files are copies of other. Please run `make data` to reconcile.

`BASIS_OMX` contains approximate Gaussian fits of selected OpenMX 2019 numerical PAOs. See the
[converter documentation](../tools/openmx/README.md) for provenance, fit thresholds, rebuilding
instructions, and limitations. These fits are not a lossless conversion or a validated replacement
for established CP2K basis/pseudopotential combinations.
