# Band Structure

This section describes methods for computing, unfolding, and analyzing electronic band structures in
periodic systems, including Kohn-Sham DFT band structures, supercell band unfolding, and
quasiparticle corrections such as *GW*. These calculations are commonly used to study band gaps,
dispersions, defect levels, and the character of electronic states.
